## Architectural debt (read this before coding)

**Checkout ≠ agent-initiated debit.**  
`openLiveCheckout()` opens `checkout.razorpay.com` and waits for a **human**. Spec says: after the window, the **agent** hits Orders + payment. For the track bar (“transactable by an AI buyer”), you need **tokenized / order-id charge** with status from **Fetch or webhook**, not only the JS `handler`.

Keep Checkout as a **fallback demo path**. Make Orders + Fetch the **primary** path locally.

### 3. Wire `fetchRazorpayPayment` (dead code today)

- Local: ngrok/cloudflare tunnel; document in README. Poll is fallback if webhook late (8–15s is a **demo** number — say so).

**Done when:** you can complete a payment, kill the tab, and still see confirm from webhook **or** poll.
